# CSS Guide — Livro Completo

Guia interativo e completo de **CSS** em **pt-BR**, cobrindo desde
fundamentos (cascata, seletores, box model) até features modernas
(`:has()`, container queries, `@scope`, subgrid, `oklch()`).

Construído com **React 19 + Vite 7 + Tailwind 4**.

## Stack
- React 19 + Vite 7
- Tailwind v4 + Radix UI
- wouter (hash routing) — funciona em GitHub Pages

## Rodar localmente
```bash
pnpm install
pnpm dev
```

## Build
```bash
pnpm build
```

## Deploy
Branch `gh-pages` → https://wallysondevs.github.io/css-guide/
